#+TITLE: Release 0.4.0 -- Retiring the Literate Source
#+AUTHOR: Metrics Miscellany Maintainers
#+OPTIONS: toc:nil num:nil

* Why now
Early development used a literate style: =metrics_miscellany.org= was the
source of truth and =./tangle.sh= generated the Python modules.  The project
has outgrown it.  The measurement that settles the question: of the 3960 lines
in =metrics_miscellany.org=, *3651 sit inside =#+begin_src= blocks*.  Prose is
*86 lines -- 2.2% of the file*.  What remains is a Python codebase wearing Org
headlines as section dividers, and paying for them with a bespoke build step,
a =check-tangle= guard, three suppressed ruff rules, and a class of bug
(silently concatenated blocks redefining the same name) that exists only
because of the tangling.

The cut is far cheaper than it looks, because the committed =.py= files
*already are* the tangled, black-formatted output -- =make check-tangle=
matches 30 of 30.  Deleting the Org file is therefore a no-op for the shipped
package: no tangling is required to perform the migration.

* Settled decisions
- Org file :: Deleted outright, not frozen under =docs/legacy/=.  A frozen
     copy invites "which one is the source?"  Git retains it; the last commit
     containing it is =d63c113=, recoverable with
     =git show d63c113:metrics_miscellany.org=.
- Release numbering :: 0.4.0 *is* the reorg.  The bug fixes already on master
     (the two =NameError= defects in =use_indices= and =heteropca=, and the
     DataMat decoupling) ship with it rather than ahead of it.  Consequence
     accepted: those defects remain live on PyPI until 0.4.0 lands.  A
     pure-bugfix 0.3.5 cut from master stays available as an escape hatch if
     that wait gets uncomfortable.
- Minor, not patch :: =utils.leverage= changes observable behavior.  PyPI's
     0.3.4 defines it twice and the later QR form wins, whose leverages sum to
     =X.shape[1]=; the surviving pseudo-inverse form sums to =rank(X)=.  The
     two disagree whenever \(X\) is rank deficient, and the values feed the HC2
     and HC3 corrections.
- =test_maunchy= :: Dies with the Org file.  =maunchy()= raises
     =NotImplementedError= on its first line, and the =COMMENT='d test is an
     unfinished matplotlib exploration with no assertions, truncated mid-line.
     It could never have passed.  The *prose* is rescued into the =maunchy()=
     docstring, since that stub survives in =tests.py=.
- Citations :: Extracted to =docs/references.bib= (commit =fdb4ecc=) from the
     maintainer's bibliography via texlive's =bibexport=.  Nothing in the build
     reads it, and nothing should: a fresh clone has no texlive.

* DONE Phase 2 -- rescue the prose

docstrings.  The rest is commentary *about* tangling and dies with it.  What
must survive:

- The factor-regression model statement (=estimators.factor_regression=).
- The randomization-inference derivation (=tests.randomization_inference=).
- The Maunchy sphericity exposition and its Muirhead p. 334 footnote.
- The eigenvalue likelihood-ratio test note, whose citation key is corrected
  from =srivastava-khastri79= to =srivastava-khatri79=.

  justification for the 0.4.0 behavior change, and it exists nowhere but the
  Org file.

Citations become bracketed author-year text resolving against
=docs/references.bib=; =hansen20:econometrics= becomes =hansen22:econometrics=,
the published Princeton edition.

Phases 1 and 2 land as one pull request, two commits, so the 86 prose lines
never exist only in history.
