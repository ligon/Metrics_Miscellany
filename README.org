Code implementing various statistical and econometric tools, developed haphazardly.  Hence the "miscellany".

Key ideas that motivate this collection:
   1. Input and output dataframes or series, or (better!) DataMats and DataVecs from the [[https://github.com/ligon/DataMat][datamat]] project.
   2. Provide clear, clean, integrated tests of estimators.
   3. Adopt semantics similar to the mathematical description of the estimation or inference problem.

See [[file:docs/index.org][docs/index.org]] for contributor guides, release checklists, and automation notes.

* Installation
#+begin_src bash
pip install git+https://github.com/ligon/Metrics_Miscellany
#+end_src

The [[https://github.com/ligon/DataMat][=datamat=]] dependency resolves from PyPI, so nothing further is needed.  To
track DataMat's development head rather than its released version, name it first
so pip prefers the checkout:

#+begin_src bash
pip install git+https://github.com/ligon/DataMat git+https://github.com/ligon/Metrics_Miscellany
#+end_src

A =git+= install works because the Python modules tangled from =metrics_miscellany.org=
are committed to the repository.  A PEP 517 build does not run =./tangle.sh=, so without
them the installed package would import modules that are not there.  Edit the Org file,
never the =.py= files; =make check-tangle= tangles into a scratch directory and fails if
the committed output has drifted from the source.
